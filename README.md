# 智控系统 - 迷宫路径规划

基于PyQt5和YOLO的视觉上位机软件，用于迷宫导航小车的路径规划与控制。

## 功能特性

### 🎯 核心功能
- **视觉检测**：使用YOLO模型检测迷宫格子中的方向箭头和数字
- **透视变换**：支持手动选点进行图像透视变换
- **路径规划**：基于BFS算法的迷宫路径规划
- **蓝牙控制**：支持HC-05/HC-06蓝牙模块与小车通信

### 🗺️ 路径规划模式
1. **原模式（方向不变）**：车头方向保持不变，直接按方向移动
2. **新模式（转向后直行）**：
   - `RIGHT N`：先右转90°，再向前走N格
   - `LEFT N`：先左转90°，再向前走N格
   - `FORWARD N`：沿当前车头方向走N格
   - `BACKWARD N`：直接后退N格（不转向）

### 📡 蓝牙测试
- 方向指令合成与发送
- STOP和RUN控制指令
- 自定义指令数组发送
- 发送记录日志

## 安装依赖

```bash
pip install -r requirements.txt
```

### 依赖列表
- PyQt5
- ultralytics (YOLO)
- opencv-python
- numpy
- pybluez (可选，蓝牙功能)

## 使用说明

### 1. 启动软件
```bash
python final3.py
```

### 2. 图像获取
- **摄像头拍照**：选择摄像头ID和分辨率，打开摄像头后拍照
- **本地图片**：选择本地迷宫图像文件

### 3. 透视变换设置
- 点击图片选择四个角点（左上→右上→右下→左下）
- 或手动输入角点坐标

### 4. 选择YOLO模型
- 点击"选择模型"按钮加载.pt或.pth格式的YOLO模型

### 5. 开始检测
- 选择箭头检测模式（模型直接检测或质心检测）
- 点击"开始检测"按钮

### 6. 设置起点
- 点击迷宫边界格子（非(0,0)位置）设置起点
- 终点固定在左上角(0,0)

### 7. 路径规划
- 选择路径规划模式
- 点击"规划路径"按钮
- 查看规划结果

### 8. 发送指令
- 连接蓝牙设备
- 点击"发送全部指令"按钮

## 指令格式

### 单个指令
```
FORWARD 4    # 向前走4格
BACKWARD 2   # 向后退2格
LEFT 3       # 左转后向前走3格（新模式）
RIGHT 5      # 右转后向前走5格（新模式）
STOP         # 停止
RUN 50       # 速度控制（-100~100）
```

### 指令数组
```
{FORWARD 4,RIGHT 2,FORWARD 3}
```

## 注意事项

1. 蓝牙功能需要安装pybluez库
2. YOLO模型需要自行训练或下载预训练模型
3. 迷宫图像需要清晰，便于网格线检测
4. 起点必须选择迷宫边界格子
